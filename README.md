# Oct Bot Legal Pages

Public policy pages for Oct Bot.


## Documents
- [Terms of Service](TERMS_OF_SERVICE.md)
- [Privacy Policy](PRIVACY_POLICY.md)


## Publishing with GitHub Pages
1. Create a **public** repository named `oct-bot-legal` and upload these files.
2. In repository **Settings → Pages**, configure deployment from the `main` branch and root folder.
3. Use the resulting Pages URL in Discord Developer Portal. The Markdown documents remain available directly in GitHub as well.


## Before publishing
The policy drafts are based on the publicly visible repository structure and feature names, not a full audit of deployed runtime behavior. Confirm the actual data fields stored, message-content access, database/hosting providers, music providers, logs, backups, retention, deletion process, and support contact. Update the Privacy Policy accordingly. These documents are templates, not legal advice.
